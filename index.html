Tutorial

Como usar o site em poucos passos

A navegação foi pensada para facilitar a compreensão dos problemas de saneamento e a participação da comunidade.

1

Explore o problema

Acesse a página Problema para entender os principais desafios de abastecimento e esgoto da cidade.

2

Veja o mapa

No menu Mapa, visualize os locais com registros de água, esgoto e outros problemas de saneamento.

3

Relate uma ocorrência

Use a página Relatar Problema para enviar informações, localização e descrição da situação encontrada.

4

Acompanhe os dados

Consulte as páginas Água, Esgoto e Painel para acompanhar indicadores e informações úteis.
